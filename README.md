# Variáveis e Tipos de Dados
## Variáveis
- Variáveis são "caixinhas" que guardam informações. Elas têm um nome e um tipo de dado.
- Exemplo: `int idade = 30;` (a variável `idade` guarda o número 30).

## Tipos de Dados
1. Tipos Primitivos (dados simples):
- `int`: números inteiros (ex: 10, -5)
- `double`: números decimais (ex: 3.14, -0.001)
- `char`: um único caractere (ex: 'A', 'b')
- `boolean`: verdadeiro ou falso (ex: true, false)
2. Tipos Não Primitivos (referência):
- `String`: texto (ex: "Olá, mundo!")
- `Object`: tipo genérico que pode guardar qualquer coisa (ex: "Posso guardar qualquer coisa", 12345)

## Resumo
- Variáveis são usadas para armazenar dados e podem ser de diferentes tipos.
- Tipos primitivos são para dados simples, enquanto tipos de referência são para objetos mais complexos.
- É importante escolher o tipo de dado correto para cada variável para garantir que o programa funcione corretamente.
